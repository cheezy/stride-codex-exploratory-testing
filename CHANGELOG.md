# Changelog

All notable changes to this project are documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [0.1.0] - 2026-07-22

### Added

- Initial scaffold of the `stride-codex-exploratory-testing` plugin — the Codex CLI
  edition of the Stride exploratory-testing plugin.
- `.codex-plugin/plugin.json` manifest (name, version, description, skills).
- Directory skeleton: `skills/`, `agents/`, `lib/`, `fixtures/`.
- Codex-only root context (`AGENTS.md`) skeleton and installers (`install.sh`,
  `install.ps1`).
- `README.md`, `LICENSE` (MIT), and `.gitignore` skeletons.

Skills, agents, documentation, and fixtures are filled in by subsequent tasks.

# Stride Exploratory Testing for Codex CLI

**Drive structured, charter-based exploratory testing sessions — from Codex CLI.**

This is the Codex CLI edition of the Stride exploratory-testing plugin. It supplies
the skills and custom agents for planning charters, running time-boxed exploratory
sessions against a running app, and capturing findings — the "explored" half of
*Tested = Checked + Explored*.

> This README is a scaffold skeleton. Installation instructions, the skill and agent
> reference, the workflow walkthrough, and the safety boundary are filled in by the
> documentation task.

## Installation

### One-liner (recommended)

Install globally so skills and agents are available in all projects:

```bash
curl -fsSL https://raw.githubusercontent.com/cheezy/stride-codex-exploratory-testing/main/install.sh | bash
```

Or install into the current project only:

```bash
curl -fsSL https://raw.githubusercontent.com/cheezy/stride-codex-exploratory-testing/main/install.sh | bash -s -- --project
```

On Windows (PowerShell), use `install.ps1` — see the documentation task output for details.
